# Веб-приложение Task Manager
Веб-приложение таск-менеджера на Python с использованием Flask

# Запуск
### Установка библиотек
```
pip install -r requirements.txt
```

### Запуск приложения
```
python run.py
```
или
```
flask --app app run
```

# Зависимости
- Python
- Flask, Flask-SQLAlchemy, Flask-Login
- PostgreSQL
